## Project Description
This repository contains the **Flutter mobile application** developed as part of
a government complaints system.

The mobile app is designed for **citizens** to submit complaints related to
governmental entities and track their status through a clear and user-friendly
interface.

This repository **only covers the mobile application**, while the backend
services and web dashboard are implemented separately by other team members.

---

## Mobile App Features
- User registration and login
- Account verification using **OTP**
- Complaint submission with:
  - Complaint type
  - Government entity selection
  - Description
  - Image and document attachments
- Complaint status tracking:
  - New
  - In Progress
  - Resolved
  - Rejected
- Real-time notifications inside the app
- Simple and intuitive UI suitable for different user groups

---

## Focus Areas
The mobile application focuses on:
- **Usability and accessibility**
- **Security in user authentication**
- **Clear user flow and validation**
- **Smooth interaction with backend APIs**
- **Responsive UI across different screen sizes**
